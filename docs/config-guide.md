# 配置文件使用指南

## 配置文件结构

项目现在包含以下配置文件：

```
config/
├── dev.yml      # 开发环境配置
├── test.yml     # 测试环境配置
└── prod.yml     # 生产环境配置
```

## 配置改进说明

### 新增配置项

1. **应用配置 (app)**
   - 应用名称、版本、调试模式

2. **HTTP 服务配置增强**
   - 请求/响应超时配置
   - 优雅关闭超时配置

3. **安全配置增强**
   - JWT 过期时间配置
   - CORS 详细配置
   - 生产环境安全检查

4. **数据库连接池配置**
   - 最大空闲连接数
   - 最大打开连接数
   - 连接生命周期配置

5. **Redis 连接池配置**
   - 连接池大小
   - 最小空闲连接
   - 连接超时配置

6. **缓存配置**
   - 不同数据类型的缓存过期时间

7. **文件上传配置**
   - 上传路径、大小限制
   - 允许的文件类型

8. **限流配置**
   - 全局、API、登录、注册限流

9. **邮件配置**
   - SMTP 服务器配置

10. **监控配置**
    - 健康检查、指标监控
    - 性能分析配置

11. **任务调度配置**
    - 定时任务的 Cron 表达式

### 环境差异化配置

- **开发环境 (dev.yml)**：调试友好，限制宽松
- **测试环境 (test.yml)**：使用内存数据库，快速执行
- **生产环境 (prod.yml)**：安全性高，性能优化

## 使用方式

### 启动不同环境

```bash
# 开发环境 (默认)
go run cmd/server/main.go

# 测试环境
go run cmd/server/main.go -conf ./config/test.yml

# 生产环境
go run cmd/server/main.go -conf ./config/prod.yml
```

### 环境变量覆盖

可以通过环境变量覆盖配置：

```bash
# 覆盖端口
export HTTP_PORT=9000
go run cmd/server/main.go

# 覆盖数据库配置
export DB_DSN="user:pass@tcp(localhost:3307)/mydb"
go run cmd/server/main.go
```

## 配置验证

新增了配置验证器，启动时会自动验证：

- 必填字段检查
- 数值范围验证
- 生产环境安全检查
- 配置逻辑一致性检查

如果配置不合理，应用会在启动时报错并给出具体原因。

## 安全建议

1. **生产环境**：
   - 修改所有默认密钥和密码
   - 使用环境变量管理敏感信息
   - 启用 HTTPS
   - 设置合理的限流值

2. **开发环境**：
   - 可以使用 `.env` 文件管理本地配置
   - 不要将 `.env` 文件提交到版本控制

3. **测试环境**：
   - 使用独立的数据库
   - 可以放宽一些限制以便测试
